# 3D-Printed Capacitive Soft Linear Actuator

## General Information

This project is a fully 3D-printed **capacitive soft linear actuator**. The device consists of a capacitor formed by two insulated, interlocked conductive combs, held apart at a defined separation by an elastomeric spring.

When a high voltage is applied across the device, the charged combs attract each other, causing the actuator to contract. When the voltage is removed, the elastomeric spring returns the device to its original position.

These actuators are highly modular and could eventually be integrated with 3D-printed joints and linkages to form an artificial musculoskeletal system for soft biomimetic robotics.

## Features

- **Monolithic 3D printing:** Fabricated using a hobbyist-level fused deposition modeling (FDM) 3D printer with three toolheads.
- **Highly modular:** Designed for integration into larger robotic systems.
- **Low-power operation:** Designed for low-current, low-power actuation.
- **Open hardware:** Licensed under [CERN-OHL-S-2.0+](https://ohwr.org/cern_ohl_s_v2.txt).
- **Low cost:** Designed to be accessible using hobbyist-level 3D printing technology.
